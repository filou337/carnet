Supprimer mon compte.

Sur cette page, vous pouvez supprimer votre compte « à deux. » et vos données, sans avoir besoin d’ouvrir ou d’installer l’appli.

Ce qui sera supprimé, ce qui restera

Supprimé immédiatement

  • Votre compte (adresse e-mail et mot de passe)
  • Votre clé personnelle chiffrée et votre code de secours
  • Votre place dans l’espace partagé
  • Si vous étiez seul(e) dans l’espace : tout le contenu de l’espace

Ce qui reste

  • Si votre moitié est encore dans l’espace, le contenu partagé reste disponible pour elle (il lui appartient aussi).
  • Les copies enregistrées sur vos appareils, jusqu’à la déconnexion ou l’effacement des données du navigateur.
  • Les journaux techniques de nos prestataires (Google, GitHub), effacés selon leurs propres durées, généralement quelques semaines.

Avant de supprimer, vous pouvez garder une copie de vos données : dans l’appli, Paramètres → Nos données → « Exporter en JSON ». La suppression est définitive : nous ne pourrons pas récupérer vos données ensuite.

Supprimer maintenant

Mot de passe oublié ? Ouvrez l’appli, touchez « Mot de passe oublié ? » pour recevoir un e-mail de réinitialisation, puis revenez sur cette page avec le nouveau mot de passe.

Autres façons de supprimer

  • Depuis l’appli : Paramètres → Mon compte → « Supprimer mon compte ».
  • Par e-mail, si vous n’arrivez plus à vous connecter : écrivez à adresse de contact à venir depuis l’adresse de votre compte. Nous supprimons le compte sous 30 jours au plus tard et vous le confirmons.
